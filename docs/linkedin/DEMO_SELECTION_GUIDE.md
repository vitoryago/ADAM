## 📹 Recording Checklist

1. **Terminal prep:**
   - [ ] Clear screen
   - [ ] Dark theme
   - [ ] Font size 18-20pt
   - [ ] Hide all chrome/tabs

2. **Before recording:**
   - [ ] Test run the script once
   - [ ] Close unnecessary apps
   - [ ] Silence notifications

3. **During recording:**
   - [ ] Let the drama build
   - [ ] Don't skip the pauses
   - [ ] Capture the full output

4. **After recording:**
   - [ ] Trim start/end
   - [ ] Add captions for mobile
   - [ ] Export as MP4

## 💡 Pro Tips

1. **Hook in 3 seconds**: The crisis must be clear immediately
2. **Show the pain**: Let viewers feel the problem
3. **ADAM enters**: Clear transition when ADAM starts
4. **Victory lap**: Emphasize the savings/improvement
