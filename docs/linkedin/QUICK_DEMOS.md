## 🎯 Quick Recording Steps

1. **Open terminal** (dark theme recommended)
2. **Navigate to directory**:
   ```bash
   cd docs/linkedin
   ```
3. **Clear screen**:
   ```bash
   clear
   ```
4. **Run chosen demo**:
   ```bash
   python scripts/clean_demo.py
   ```
5. **Record screen** (QuickTime, OBS, etc.)

## 📱 LinkedIn Video Specs

- **Feed videos**: 3 seconds - 10 minutes
- **Autoplay**: No sound, use captions
- **Aspect ratio**: 1:1 or 16:9
- **File size**: Under 5GB
- **Resolution**: 1080p recommended

## 💡 Pro Tips

1. **For 10-second videos**: Use `clean_demo.py` - it's the cleanest
2. **Zoom in**: Make text large and readable on mobile
3. **Add captions**: Most LinkedIn videos play muted
4. **Hook fast**: Show the problem in first 2 seconds
5. **End strong**: Show the savings/improvement clearly
