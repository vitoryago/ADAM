# ADAM LinkedIn Demonstration Suite

This directory contains professional demonstrations of ADAM's capabilities for LinkedIn showcase. The demos focus on:

1. **BigQuery Performance Optimization** - How ADAM learns and improves SQL query performance
2. **ReAct Framework Integration** - Reasoning and Acting capabilities in problem-solving
3. **Memory Network Visualization** - Visual representation of ADAM's associative memory

## 🎯 Demo Structure

```
docs/linkedin/
├── scripts/
│   ├── seed_bigquery_memory.py      # Seeds memory with BigQuery scenarios
│   ├── run_bigquery_demo.py         # Demonstrates performance improvements
│   ├── react_demonstration.py       # Shows ReAct reasoning capabilities
│   └── visualize_memory_network.py  # Creates memory network visualizations
├── data/
│   ├── bigquery_scenarios.json      # Pre-defined BigQuery problems
│   └── react_scenarios.json         # ReAct test cases
├── outputs/
│   └── [Generated demo outputs]
└── images/
    └── [Memory network visualizations]
```

## 🚀 Quick Start

1. **Seed the memory with BigQuery scenarios:**
   ```bash
   python docs/linkedin/scripts/seed_bigquery_memory.py
   ```

2. **Run the BigQuery optimization demo:**
   ```bash
   python docs/linkedin/scripts/run_bigquery_demo.py
   ```

3. **Demonstrate ReAct framework:**
   ```bash
   python docs/linkedin/scripts/react_demonstration.py
   ```

4. **Generate memory visualizations:**
   ```bash
   python docs/linkedin/scripts/visualize_memory_network.py
   ```

- Focus on outcomes rather than internals
- Be suitable for public sharing on LinkedIn
