# Day 021: Web Interface Evolution - From Chatbot to AI Coworker 🖥️

## Date: 2025-07-15

## Summary
Today we transformed ADAM's web interface from a repetitive chatbot into a natural AI coworker that maintains conversational flow and adapts its UI based on capabilities.

## The Problems We Solved

### 1. Repetitive Greetings
ADAM kept introducing himself on every message:
- "Hello! I'm ADAM, your AI assistant..."
- "Hi there! How can I help you today?"
- Even on the 10th message in a conversation!

### 2. Poor Model Visibility
The model selector was hidden in the sidebar, making it hard to:
- See which model was being used
- Understand costs
- Switch models quickly

### 3. No Image Support
Despite having vision-capable models, there was no way to upload images.

## The Solutions

### 1. Message Number Tracking
Implemented conversation awareness:

```python
# Count messages in current conversation
user_messages = [msg for msg in st.session_state.messages if msg["role"] == "user"]
message_number = len(user_messages) + 1

system_prompt = f"""You are ADAM, a helpful AI coworker. This is message #{message_number} in our current conversation.

IMPORTANT BEHAVIORAL RULES:
- DO NOT introduce yourself or greet the user (no "Hi!", "I'm ADAM", etc.)
- DO NOT use emojis unless specifically requested
- Be direct and conversational, like a coworker sitting next to them
- Only introduce yourself if explicitly asked "who are you?" or similar
- For message #2 and beyond, continue the conversation naturally without greetings
"""
```

### 2. Top-Level Model Selector
Moved model selection to the header with visual enhancements:

```python
# Header with model selector
col1, col2, col3 = st.columns([3, 2, 1])

with col2:
    # Model selector at the top with descriptions
    selected_model = st.selectbox(
        "Model",
        options=available_models,
        format_func=lambda x: f"{x} 🖼️" if supports_vision else x
    )
    st.caption(model_info.get(selected_model, ""))

with col3:
    # Real-time cost display
    if st.session_state.total_cost > 0:
        st.metric("Cost", f"${st.session_state.total_cost:.4f}")
```

### 3. Conditional Image Upload
Smart UI that adapts to model capabilities:

```python
# Only show image upload for vision models
model_config = st.session_state.llm_config.get_model_config(selected_model)
if model_config and model_config.supports_vision:
    uploaded_file = st.file_uploader(
        "Upload an image (optional) 🖼️",
        type=['png', 'jpg', 'jpeg', 'gif', 'webp'],
        help=f"{selected_model} supports image analysis"
    )
else:
    if st.session_state.get('image_upload'):
        st.info(f"ℹ️ {selected_model} doesn't support images. Switch to a vision model.")
```

```python
@error_boundary
def process_message(self, prompt: str, image_data: Optional[bytes] = None):
    try:
        # Process message
    except Exception as e:
        logger.error(f"Error: {str(e)}", exc_info=True)
        st.error(f"An error occurred: {str(e)}")
        if st.checkbox("Show error details"):
            st.code(traceback.format_exc())
```
