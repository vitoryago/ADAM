- Images: ~1280 tokens typical (256 tokens per tile)

## Technical Deep Dive

### Image Token Calculation
Grok's image processing:
- Images broken into 448x448 pixel tiles
- Each tile = 256 tokens
- Maximum 6 tiles per image
- Formula: `(# of tiles + 1) * 256` tokens

### Separate Input/Output Pricing
Enhanced the model configuration to support different pricing:

```python
@dataclass
class ModelConfig:
    cost_per_1k_tokens: float = 0.0  # Backward compatibility
    cost_per_1k_input_tokens: Optional[float] = None
    cost_per_1k_output_tokens: Optional[float] = None
```

## Key Learnings

### 1. API Integration Patterns
- Always check official SDK documentation
- Use the provided helper functions (like `image()`)
- Handle both base64 and URL formats (even if only one implemented)

### 2. Multimodal Cost Considerations
- Image processing can be expensive
- Token counts vary significantly by image size
- Separate input/output pricing becoming standard

### 3. UI/UX for Multimodal
- Clear visual indicators for capabilities
- Conditional UI elements based on model support
- Cost transparency is crucial for users
