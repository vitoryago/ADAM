# Day 016: Voice Integration Architecture Design

**Date**: July 26, 2025

## Summary
Designed and began implementing a comprehensive voice integration system for ADAM, separating voice input/output from core reasoning.

## Voice Architecture Strategy

### Core Principle
"I just want to use the model to speak, translate to text and then the reasoning and the answer will be done by Grok or OpenAI models. And then the voice model will just read and explain that"

### Pipeline Design
```
Voice Input → STT (Whisper) → Text → ADAM (Grok/OpenAI) → Response → TTS (ElevenLabs) → Voice Output
```

## What We Built

### 1. Voice Service (`voice_service.py`)
- **Speech-to-Text (STT)**: OpenAI Whisper integration
- **Text-to-Speech (TTS)**: ElevenLabs integration
- Support for multiple TTS models
- Streaming and batch processing
- Voice configuration management

### 2. WebSocket Service (`voice_websocket.py`)
- Real-time voice streaming with ElevenLabs
- Multi-context WebSocket support
- Character-level alignment for lip-sync
- Low-latency audio transmission

### 3. Voice API Endpoints (`routers/voice.py`)
- `/api/voice/transcribe` - Audio to text conversion
- `/api/voice/synthesize` - Text to speech conversion
- `/api/voice/voices` - List available voices
- `/api/voice/voice-chat` - Complete voice conversation
- `/ws/voice-stream` - WebSocket for real-time streaming

### 4. Frontend Components
- **VoiceInput**: Microphone recording with Web Audio API
- **VoicePlayer**: Audio playback with volume control
- Both components integrate seamlessly with chat UI

## Voice Model Research

### Recommended STT Models
1. **OpenAI Whisper** (Implemented)
   - High accuracy
   - Multi-language support
   - Good with accents
   - Cost: ~$0.006/minute

2. **Local Whisper** (Alternative)
   - No API costs
   - Privacy-friendly
   - Requires GPU

### Recommended TTS Models
1. **ElevenLabs** (Implemented)
   - Most realistic voices
   - Voice cloning capability
   - Cost: ~$0.18/1000 chars
   - Models: multilingual_v2, turbo_v2

2. **XTTS-v2** (Open source alternative)
   - Free to run
   - Good quality
   - Requires local GPU

3. **Other July 2025 Models**
   - Moshi (ultra-low latency)
   - Qwen2.5-Omni (multilingual)
   - Spark-TTS (Chinese focus)

## Key Design Decisions

1. **Separation of Concerns**
   - Voice is purely input/output layer
   - Core intelligence remains with Grok/OpenAI
   - Clean API boundaries

2. **Format Standards**
   - WebM for browser recording
   - MP3 for universal playback
   - Base64 for JSON transmission

3. **User Experience**
   - One-click recording
   - Auto-play option for responses
   - Visual feedback during processing
