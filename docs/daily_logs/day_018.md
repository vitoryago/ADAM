## Integration Patterns Established

### 1. Service Layer Pattern
```
Router → Service → External API
   ↓        ↓           ↓
FastAPI  Business    Provider
         Logic      (OpenAI/xAI)
```

**Benefits**:
- Clean separation of concerns
- Easy to test and mock
- Provider swapping capability

### 2. Feature Toggle Pattern
```typescript
// Frontend toggles
const [searchEnabled, setSearchEnabled] = useState(false);
const [voiceEnabled, setVoiceEnabled] = useState(true);

// Pass to backend
requestBody.use_search = searchEnabled;
requestBody.voice_config = voiceEnabled ? voiceConfig : null;
```

**Benefits**:
- User control over features
- Gradual rollout capability
- Cost optimization

### 3. Multi-Modal Processing Pattern
```python
async def process_message(
    text: str,
    image: Optional[str] = None,
    audio: Optional[bytes] = None,
    search: bool = False
):
    # 1. Pre-process inputs
    if audio:
        text = await transcribe(audio)
    
    # 2. Route to appropriate model
    model = select_model(text, image, search)
    
    # 3. Process with enhancements
    if search:
        response = await llm_with_search(text, model)
    else:
        response = await llm_complete(text, model, image)
    
    # 4. Post-process outputs
    if voice_enabled:
        audio = await synthesize(response.text)
    
    return response, audio
```

## Error Handling Patterns

### Backend Error Handling
```python
try:
    result = await external_api_call()
except HTTPException as e:
    # Re-raise HTTP exceptions
    raise
except Exception as e:
    logger.error(f"Service error: {e}")
    # Fallback or graceful degradation
    if fallback_available:
        result = await fallback_service()
    else:
        raise HTTPException(500, detail=str(e))
```

### Frontend Error Handling
```typescript
try {
  const response = await apiRequest("POST", endpoint, data);
  // Process response
} catch (error) {
  toast({
    title: "Error",
    description: getErrorMessage(error),
    variant: "destructive"
  });
  // Fallback UI state
  setFallbackMode(true);
}
```

## Performance Optimizations Applied

1. **Streaming Responses**

2. **Intelligent Routing**

3. **Caching Strategy**

   - Environment variables only
   - Fallback to defaults carefully

2. **Input Validation**
   - File size limits (20MB)
   - Audio format validation
   - Text length limits
