# Day 019: Temporal Memory Scoring - Time-Aware Retrieval 🕰️

## Date: 2025-07-12

## Summary
Today we implemented temporal memory scoring, adding sophisticated time-awareness to ADAM's retrieval system. This ensures recent memories are appropriately prioritized while maintaining relevance.

## The Problem

ADAM's retrieval was purely based on semantic similarity, leading to:
- Old memories dominating results even when recent ones were more relevant
- No consideration for the natural "freshness" of information
- Missing temporal context that humans naturally use

Example: Asking "what did we discuss about Python?" would return a 6-month-old conversation about Python basics instead of yesterday's discussion about Python decorators.

## The Solution: TemporalMemoryScorer

Built a configurable temporal scoring system inspired by:
- **Exponential Decay**: Natural forgetting curve
- **Boost Windows**: Increased relevance for recent timeframes
- **Semantic-Temporal Balance**: Combining relevance with recency

### Core Algorithm

```python
def calculate_temporal_score(self, timestamp: datetime) -> float:
    # Time-based decay
    hours_elapsed = (datetime.now(timezone.utc) - timestamp).total_seconds() / 3600
    days_elapsed = hours_elapsed / 24
    
    # Exponential decay
    temporal_score = math.exp(-self.config.decay_rate * days_elapsed)
    
    # Apply boost windows
    if hours_elapsed <= self.config.boost_window_hours:
        boost_factor = self.config.recent_boost_factor
        # Gradual boost decay
        window_position = hours_elapsed / self.config.boost_window_hours
        adjusted_boost = 1 + (boost_factor - 1) * (1 - window_position)
        temporal_score *= adjusted_boost
    
    return max(self.config.min_temporal_score, temporal_score)
```

### Configurable Parameters

```python
@dataclass
class TemporalScoringConfig:
    # How fast memories decay
    decay_rate: float = 0.1
    
    # Recent memory boost window (hours)
    boost_window_hours: int = 24
    recent_boost_factor: float = 2.0
    
    # Minimum temporal score
    min_temporal_score: float = 0.1
    
    # Balance between similarity and time
    similarity_weight: float = 0.7
    temporal_weight: float = 0.3
```

## Advanced Features

### 1. Query-Aware Temporal Adjustment

Different queries need different temporal handling:

```python
def analyze_temporal_intent(self, query: str) -> TemporalIntent:
    query_lower = query.lower()
    
    # Recent-focused queries
    if any(word in query_lower for word in ['recent', 'latest', 'today', 'yesterday']):
        return TemporalIntent.RECENT_FOCUSED
    
    # Historical queries
    if any(word in query_lower for word in ['history', 'all time', 'ever']):
        return TemporalIntent.HISTORICAL
    
    # Default balanced approach
    return TemporalIntent.BALANCED
```

### 2. Adaptive Decay Rates

Based on content type:
- **Conversations**: Faster decay (0.2)
- **Code/Documentation**: Slower decay (0.05)
- **Errors/Solutions**: Very slow decay (0.01)

### 3. Time-Based Clustering

Prevents temporal score from overwhelming semantic relevance:

```python
def apply_temporal_clustering(self, memories: List[Dict]) -> List[Dict]:
    # Group by time periods
    clusters = {
        'today': [],
        'this_week': [],
        'this_month': [],
        'older': []
    }
    
    # Assign memories to clusters
    for memory in memories:
        hours_ago = self._get_hours_elapsed(memory['timestamp'])
        if hours_ago < 24:
            clusters['today'].append(memory)
        elif hours_ago < 168:  # 7 days
            clusters['this_week'].append(memory)
        # ... etc
    
    # Take top results from each cluster
    balanced_results = []
    for cluster in clusters.values():
        balanced_results.extend(cluster[:3])
    
    return balanced_results
```

## Mathematical Foundation

### Exponential Decay Function
```
f(t) = e^(-λt)
```
Where:
- t = time elapsed (days)
- λ = decay rate
- f(t) = temporal score

### Combined Scoring Function
```
S_final = w_s × S_semantic + w_t × S_temporal
```
Where:
- w_s + w_t = 1.0
- S_semantic ∈ [0, 1]
- S_temporal ∈ [min_score, 1]
