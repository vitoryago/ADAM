## 🚀 Quick Start

### 1. Open VSCode
```bash
"/Users/vitoryago/Downloads/Visual Studio Code.app/Contents/Resources/app/bin/code" .
```

### 2. Configure Your API Key
1. Press `Cmd+,` to open Settings
2. Search for "adam"
3. Add one of these:
   - `adam.openaiApiKey`: Your OpenAI API key
   - `adam.grokApiKey`: Your Grok/xAI API key

### 3. Start Using ADAM
- **Open Chat:** Press `Cmd+Shift+A`
- **Explain Code:** Select code and press `Cmd+Shift+E`
- **Activity Bar:** Click the ADAM icon on the left sidebar

## 💡 Pro Tip: Add 'code' Command

To use `code` command anywhere, add this to your `~/.zshrc`:
```bash
alias code='"/Users/vitoryago/Downloads/Visual Studio Code.app/Contents/Resources/app/bin/code"'
```

Then run:
```bash
source ~/.zshrc
```
