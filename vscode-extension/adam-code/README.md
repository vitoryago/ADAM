# ADAM VSCode Extension

Simple AI assistant that connects to your ADAM backend.

## Features
- Chat interface (Cmd+Shift+A)
- Backend integration with RAG and memory
- Auto-starts backend if not running

## Setup
1. Start backend: `cd /Users/vitoryago/ADAM/src/adam_v2 && python main.py`
2. Open VSCode
3. Press Cmd+Shift+A to open ADAM chat

## Requirements
- ADAM backend running on http://localhost:8000
- Project ID: 3a859e97-16fd-46c6-b018-1ede9fade704

## Usage
Just type your questions and ADAM will use the backend to answer with full context and memory.
